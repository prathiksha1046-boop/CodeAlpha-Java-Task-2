# CodeAlpha-Java-Task-2
CodeAlpha Java Intership - Task 2: Stock Trading Platform

## About the Project
This project is developed as part of the CodeAlpha Java Internship.

The Stock Trading Platform is a Java-based application that simulates basic stock trading operations. Users can view market data, buy and sell stocks, manage their portfolio, and view transaction details.

## Features
- View available stocks and market prices
- Buy stocks
- Sell stocks
- Manage user portfolio
- Check available balance
- View transaction details

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java file.
4. Run the `StockTradingPlatform` class.
